# Certified intrinsic-period master: new posthoc research protocol

This hypothesis was derived after the predeclared size family's smaller
period was recognized, before applying a new reduction to any existing
research relation or generating the checks below. It is a new posthoc method,
not a prospective prediction of the old R04 experiments. It cannot overwrite
their fixed-modulus no-compression results. No hardware or runtime claim.

Candidate result: for a nonempty canonical profile Q_d, an e|d is a period
of its exact function H_d iff translation by e preserves its residue/span
pairs. The least e is recoverable as the period of the circular word of
successive reset gaps and spans (standard string-period computation, not a
new string algorithm). Let Q_e=kappa_e Pi_e Q_d. Under a verified exact
period-lift binding, every physical P uses remainder modulus gcd(P,e),
retaining physical load (K-1)P. The result is conditional on this additional
period evidence; it must not contradict Theorem 4's universal impossibility
for an arbitrary projected payload without a lift certificate. Prefix and
epoch/producer bindings remain unchanged.

Before any checks: enumerate every nonempty profile with d=1..6 and each
residue absent or assigned integer span 0..3 (19,524 profiles). Independently
compare direct function periods, pair-translation periods, word/KMP period,
explicit lift reconstruction, every target m|d, and all physical P=1..2d,
K in {1,2,4}, every phase. Retain all counterexamples, including no reduction.
Test fixed d=12 projected-g=4/target-m=6 singleton relations from the existing
nondivisor argument to demonstrate that ignoring the lift gate is invalid.
Test spans as well as residues; a repeated support alone is insufficient.

Apply without tuning to all 80 line relations in the published R04 shared
controller input (40 controllers x2 lines), plus the seven already declared
p=16..1024 single-source size cases. Report per-line/case fundamental e,
master pair count, all no-reduction cases, and explicit complete-record byte
sizes with added period metadata and the unchanged physical prefix. Use the
old complete-record encoder with a documented new eight-byte e field;
do not count only pair payloads or call results arbitrary bit minimality.
For the 80 old relations, check every one of the 74,000 per-line policy
slacks in the original grid, not just favorable configurations. New calendar
relations, if later passed independently, are a separate extension and must
be all retained, not substituted for unfavorable original cases.

Meaningful mutation controls: ignore span equality in the period test; use
the new e in the physical load term; omit periodic-lift gate; project the
old prefix using e. Each claimed detection must come from an actual executed
checker and a concrete counterexample. No generic failure count without
an input. A fresh independent validator must reconstruct the math, exact
phase tests, source bindings and encoding before any manuscript claim or
public release. If the candidate result fails, preserve failure and withhold
it. Raw profiles/review scores and old proofs remain unchanged.

Pre-encoding clarification: each new complete-record line adds eight bytes
for e and 32 bytes binding the expanded original canonical profile, forty
bytes per line rather than the preliminary eight-byte estimate. Expected
profile/binding digests are supplied by the trusted producer/source registry;
an untrusted digest inside a record is not self-authenticating. Count the
full extra eighty bytes per two-line record, including all net regressions.

Before applying the method to the seven declared size cases, use a
generalized one-line full-record baseline with the same R04 field layout,
new `HUFULL05` type and an actual one-line parser; do not label it an
existing R04 two-line record. New period records retain all four bindings,
original d, and the additional e/profile digest. Check every phase of the
original H_d against the reduced H_e and actual serialized round trips.
Also check K={1,2,4}, P in the deduplicated set {1,2,p,q,d,d+1,3p} and
phases {0,floor(P/2),P-1}; this is a finite supplement to the proof and
the complete original-policy census, not universal experimental exhaustion.
An adaptive reader may keep the original full record if the period record
is larger. Report that option separately; never erase the period-record
regressions on the original forty controllers.
