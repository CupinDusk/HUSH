## Denominators and transformations

Use every existing R30 entry: p=1..12, q=1..3p, s0=0..p-1 (1950),
excluding exactly the 328 entries with a reachable poll/receipt tie.
There are 1622 admitted parameter entries, not independent programs;
764 have nonempty transients. Queries below concern recurrent cycles
only. A positive cycle query is not a prefix-safe runtime installation.

Use the same storage rule g=d/gcd(d,3) for every admitted entry.
This rule was chosen after the earlier g27/d81 and g140/d420 examples;
it is not a pre-observation or optimal deployment policy. The original
grid is exactly the earlier P<=2p, K=1/2, all phases. The expanded grid
P<=4p, K=1..5, all phases was chosen after those illustrations but before
these aggregate counts. Report both grids. They are deterministic finite
sensitivity domains, not query-frequency or population-utility estimates.

Raw/master/stored sizes count parameter entries. Query-size comparisons
count each parameter-entry/P interface once, without phase/load weighting.
Policy-query counts include every declared phase/load, supported or not.
Four disjoint outcomes are supported both-positive, supported service-only
positive, supported unknown and unsupported. Nonpositive means unknown,
not an observed miss. Unsupported m=gcd(P,d) not dividing g needs a master
or producer; a worker cannot return a scalar answer from this payload.

Every exact query is compared with explicit recurrent expansion over
P/gcd(P,d) copies. Fair completion uses the same actual completion residues,
tight cycle J/A and the same canonicalization, not an artificially unreduced
baseline. D<=Delta and the joint-witness iff are checked at each interface.

Full masters reduce in 0/1622 entries. Storage reduces in 220/1622 entries.
The original grid has zero rescued positive queries; the expanded grid has
143818 supported rescues in 646 entries. Of 61176 expanded interfaces,
service terms are fewer/equal/more than completion at 4789/49706/6681.
These unfavorable cases preclude universal compression or utility claims.

## Source-control invariant of the twelve-phase graph

For p12/q35/s0=0 the maximum accepted-read latency is23<35. Every send
normalizes one outstanding packet, no older accepted snapshot and a poll at
s+35. No poll occurs while a packet remains outstanding. Before receipt,
the occupied R0/R1 fields identify that packet; receipt removes it while the
poll at s+35 remains scheduled. Thus time modulo lcm(420,P) and the complete
endpoint fields determine pending/wait/poll flags; they are derived state,
not omitted independently variable source state. Services35k and receipts
36k+12 repeat after420 ticks. Translation preserves guards, and ID relabeling
only after receipt cannot alias a live request. Worklist closure and both
WU successors cover the binary zero-byte alphabet, without revocation.

For the branch source, the full key also contains M,W,ell,alpha,gamma.
The callback delay tau<=b+p<2p and response delay c-s<2p imply service ages
below4p and ell<2p. Branch bits exist only on actual callbacks. Relative
updates, the complete ordered tick, and no-alias ID relabeling establish
manual congruence. Independent edge replay checks arithmetic conditional
on the predecessor/configuration/input; replay alone is not completeness.

Composition is a valid-tag/control result for matching reads and optional
zero-byte WU (plus actual-callback branch bits), not arbitrary payload
coherence. A positive relation must cover both installation/prefix and cycle.
The seven previously executed p9 admission negatives are clock10, epoch8,
shared WU lane, revoked token, horizon exceeded, invalid entry and unproved
hot change. The prescribed binding also covers response stages, sink and
implementation digest; no claim that every field was negatively mutated.

## Novelty and visual provenance

WU, silent expiry, tuning and the analysis/cache layout are inherited HUSH
LBR concepts. Min-convolution, own-site dominance, essential covers and
relational domains are prior mathematical machinery. The current claims
are the fixed-output cyclic reset specialization/sparse construction, the
joint timing-extrema witness test and the maximal universal payload-only
modulus rule, including master/gcd reuse while keeping physical load.
The aggregate is scope characterization, not another claimed mechanism.
