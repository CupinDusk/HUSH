retains all earlier native measurements, full training/held-out records,
receiver proofs and unknowns, full FF-bank mapping estimates, conditional
source studies and costs. This entry adds four portable components and does
not replace or rewrite the earlier scientific records.

Use Python3.12+ and the standard library:

    python -B -X utf8 replay.py --quick
    python -B -X utf8 replay.py --quick --output ./verified-quick

Replay checks every top-level/archive-member hash, extracts into a new
temporary directory, runs each component's default offline checker, then
checks that all packaged member bytes remain unchanged. It launches no native
simulator, CXXRTL execution, compiler, synthesis tool, SAT solver or remote job.
Integrity PASS remains distinct from each retained proof or execution outcome.

**receiver-endpoint** records108 new prospective native executions after selecting
receiver-oriented plans from the already-existing1692 R37 training rows. The
complete old1800 records are retained for retrospective R reduction, including
the108 original held-out rows; reuse is not counted as a new execution. All
new controls,18 signed Fixed/Phase pairs, adverse receiver results and separate
J/WU results remain visible. R is the receiver output-ready/per-element-checked
latency from marker0 to the latest reader marker10/11/12: reader checks, free,
helpers and barriers before those markers are included. It excludes the
requirement for writer completion, main joins and each done-return epilogue.

good/printf. R and J therefore answer different completion questions; neither
measured maximum is a processor WCET guarantee. WU counts completed L1 update
transactions, not energy, fanout or global write completion.
