# HUSH matched native controls and three source-input paths

This release extends the preceding immutable research packages. It contains
all matched native K1/WI/WU/suppression/phase/frozen-fixed/training-fastest
comparisons, all 16 fixed diagnostics and exact descriptive tolerance regimes.
These are arithmetic over existing measurements; no heldout retuning or new
native execution is claimed. The 64-KiB phase remains an undeployed diagnostic.
All signed outcomes and cases where K1, suppression or K2 are preferable remain.

    python -B -X utf8 native-comparators/replay.py
    python -B -X utf8 replay_sources.py

The binary ZIP is a lossless container for 44 text-only source-input files:
three pinned TACLeBench sources with original license notices, declared-order
instruments, default output vectors/traces, 72 complete timing maps, bound
certificates and independent checkers. It contains no executable, PDB, private
compiler path, simulator overlay/binary, account, host, credential or manuscript.
Clone/download the repository folder, then run the commands above with Python
3.12+. To inspect the source, unzip source-kernels-inputs.zip normally.

Original and instrumented C programs were freshly compiled locally; public
normalized receipts preserve compiler version, argv structure and source/output
hashes. Numerical equivalence is for default input and the recorded build.
The declared source operand order is not the original optimized machine order.
Comprehensive compute/private/helper bounds and the clean partition are supplied;
these checks do not extract platform WCET or measure multicore kernel speedup.
Matrix1/complex_updates tie at all 48 maps; IIR improves its conditional bound
70--210 cycles across 24 maps, up to70/334=20.9581%. All cases remain available.
