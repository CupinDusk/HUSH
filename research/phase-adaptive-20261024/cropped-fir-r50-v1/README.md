# Cropped FIR phase-retention research data

Run `python -B -X utf8 VERIFY.py`. Python standard library only, no network
or simulator execution. It verifies every payload hash/size, recomputes
all nine primary min-M choices and all27 secondary budget queries from the
complete9630-row numeric catalogue, reconstructs and independently checks
the included compact traces, and recomputes all82 carry/forgetful classifiers.

This bundle includes all54 original validation traces plus192 additional
frontier checks, nominal traces for all41 frozen frontier plans and four
compatibility/gate traces. Identical54 conditions were reused, never run
twice. Per-case receipts and complete execution receipts hash-bind all
original raw outputs, including training traces retained locally. The
complete9630 training trace bytes are NOT included; the bundle can audit
tables and included observed values but cannot independently replay every
training word without those local traces or a new run.

The Windows x86-64 cap0/cap1 binaries are the already-compiled receiver
simulators, with generated model sources, driver, owned RTL and exact origin
hashes. No new build was performed. Their interface is
`cap0.exe OPS K0 K1 K2 GAP PHI FIXED WRITER_COUNT FLUSH_MASK`; run in a fresh
directory. They generate response/commit CSVs. New invocations are new
scientific executions and must be recorded separately; VERIFY never starts
them. Building sources separately requires the public Yosys CXXRTL headers
used by the prior source collection. Author runners preserve original
workspace paths/provenance and are archival, not a portable one-click launcher.

All three crops are output-region variants of one DSP port path, with
supplied C; they are not independent CPU benchmarks. WU is measured
transactions, not certified traffic. Primary min-M choices favor Fixed in
all three variants. The fully reported secondary q4/B5840 point has equal
M3245 and observedWU99/95/84 for Fixed/Future/Cap; all other budgets and
adverse outcomes remain in the tables. Carry-reset is an explicitly post-hoc
analysis-forgetting ablation, not physical cache flush or faster execution.

The prior-lastuse folder preserves all1020 stronger-Fixed numeric outcomes
and source/gate hashes. Paper files, reviews, third-party PDFs, private
overlays, identities, credentials and server configuration are excluded.
