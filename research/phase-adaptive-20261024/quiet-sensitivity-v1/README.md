# HUSH quiet/private-suffix sensitivity v1

Download and unzip hush-quiet-sensitivity-v1.zip into a new directory, then run:

    python -B r10_quiet_study.py --model-dir . --output replay.json

Python 3.12 standard library is sufficient. Compare summary and rows with expected_results.json; elapsed time is not an equality field. The bundle includes the original public model, its defaults, a prospectively fixed experiment protocol, standalone driver, expected results and full methodological README. It contains no manuscript, private overlay or server materials.

The six lengths and all eight margins/two tick phases are retained. This is a controlled synthetic sensitivity, not native application performance. The unchanged model and the main experiments remain in the immutable phase-adaptive v5 package.
