# R53 deterministic analyses

budget-envelopes-r53-v1 covers all 20,223 family/budget rows for all seven existing settings. VERIFY.py recomputes every integer-budget choice against the full catalogues and evaluates the unchanged choices in all six frozen conditions. It starts no simulation. The full signed intervals are retained. FIR q4 has a nominal and six-condition traffic-benefit interval B5776–6004. Matrix q4/private64 has a nominal benefit interval B7067–7216 (31.90% Cap reduction), with six-condition Cap/Fixed ratios0.625–1.193; these are observed, not guaranteed, traffic ratios.

phase-diagnostics-r53-v1 is a21KB verifier for all41 FIR frontier plans and all9 budget choices. Its README explains how to supply the earlier cropped-FIR archive. All phase tables reconstruct byte-exactly, including same-execution carry-in/phase-local classifications.

Both are post-study deterministic reductions of existing frozen receiver simulations, with0 new timing runs. The four provided audit/ZIP files contain research code and numeric evidence only; no manuscript or confidential reviews.
