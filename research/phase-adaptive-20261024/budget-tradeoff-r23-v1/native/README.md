# Same-offset native tradeoffs, R23

Author-side evidence package. 66 original R20 frozen points plus six new preregistered post-selection N16 matched-suppression points. No policy reselection. Run `python -B -X utf8 replay.py --out replay-output` using Python3 stdlib. The four JSON inputs are sanitized counters, frozen rules, original training candidates and frozen-fastest time anchors. No simulator binary, private implementation, server identity, relay or credentials are included. MEASUREMENTS.json retains immutable input/result hashes and all six new checksum checks. Source code inspection supports the intervention explanation in RESULTS.md; this counter package does not independently prove source-level correctness or native/RTL equivalence.

Compact text storage: MEASUREMENTS.json and TRAIN_CANDIDATES.json are losslessly gzip/base64 encoded. replay.py validates the fixed encoded size/hash, strictly decodes base64, inflates gzip, then validates exact decoded bytes/SHA256 before using the original JSON logic. The decoded raw hashes in AUDIT.json remain identical to PUBLIC. The loader does not execute input or write decoded files. Run replay with --out pointing to a separate directory to preserve the staged tree.
