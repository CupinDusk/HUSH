its conditional receiver budget from782 explicit global-data events.
Compute/private/helper inputs remain supplied comprehensive upper bounds.
Run emit_certificate.py then check_certificate.py inside fir/; no server,
native simulator or compiler is required. Source/reuse-distance/deadline
checks are independent of the emitter's transfer implementation.

native/ contains six new preregistered, post-selection N16 suppression
measurements and all same-offset fixed/phase/suppression comparisons.
Run its replay.py with Python stdlib. Fixed policies/rules are unchanged;
training caps are empirical objectives and do not certify heldout WCET.

descriptor_tools.py checks one-byte-per-phase reference payload encoding
and exact enumeration formulas. Metadata/tick state are separate; no native
descriptor memory-size measurement or search pruning is claimed.

All signed outcomes are retained. No private simulator overlay, binary,
host/account/credential, manuscript, review or actual venue submission.
