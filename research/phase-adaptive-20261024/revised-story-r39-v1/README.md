# Phase-Adaptive HUSH: deployment boundaries and changing data

The [preceding pinned collection](https://github.com/CupinDusk/HUSH/tree/677424f7ae554b1d945735049bbbfd5dac0bbab9/research/phase-adaptive-20261024/revised-story-r38-v1)
retains all prior source/native studies, selection freezes, adverse outcomes,
proofs, mapping records, unknowns, attempts and the native255 semantics erratum.
No preceding study is rewritten.

Run with Python3.12+ and the standard library:

    python -B -X utf8 replay.py --quick

The quick replay verifies all hashes and independently recomputes frozen
evidence in a new directory. It does not compile or launch a native simulator,
SAT solver, synthesis tool or remote job. Integrity is distinct from a
correctness proof, an execution outcome or a processor WCET guarantee.

native-boundary-freshness characterizes the already-frozen Matrix receiver
plans over a declared gap/quiescence grid, retaining all controls, signed
R/J/WU outcomes and deterministic duplicate identities. Matrix was selected
for this exploratory characterization after the previous positive cases
were known. No per-condition reoptimization or general superiority claim
is made. Its separate changing-data integration probes document actual
synchronization, value oracles, cache/phase events, finite coverage and all
failed or completed attempts. A stale-observation rejection tests the
checker, not an unexecuted mutant DUT. R is output-ready/per-element-checked
receiver latency; J includes writer/joins. Neither measured maximum is WCET.

tight-budget-transfer retrospectively selects from the complete existing
M0 training menu at eight predeclared budgets, freezes plans, then executes
the new registered offset/gap matrix. Old training reuse is not a new
execution. All feasible/infeasible, fallback, signed and duplicate records
remain available. The B70000 display case was selected before its result.
The no-holding/all-shared-unknown contract is a conservative analytical
abstraction under identical supplied costs; it is not the strongest
PMSI/DISCO/WI analysis or a measured protocol comparison. The infinity
holding reference and strongest admitted free-flush Fixed are retained.
A short transfer trace is independently reconstructed from the actual
algorithm, including private allocation, old lifetime, phase costs and
miss-service debits. Supplied compute/runtime bounds remain external inputs.

Scientific bytes and legal source/attribution are preserved. No manuscript,
assessment, private simulator overlay/binary, server settings or credentials
are included. Each component records registration, exact scope and replay.
