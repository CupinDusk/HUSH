reconstructs saved results. It launches no native simulator, cycle-model grid,
SAT solver, synthesis tool or STA tool. Component READMEs identify separately
registered executions, tool/library bindings, constraints, assumptions, exact
attempt counts and the scope of any optional full rerun.

the preceding mapped JSON exports. Those exports and incomplete timing attempts
remain historical evidence; the current circuit comparison uses only the gated
R42 remapping and timing results.

The component collection addresses fixed-plan capacity checks, matched-capacity
selection and validation, phase-event cost, and pre-layout bank/controller timing.
Every component preserves all signed outcomes and failed attempts within its
registered execution scope. A mapped combinational delay and pre-layout STA
remain distinct measurements; neither establishes routed full-CPU timing.
The static certificate and native application measurements retain their
separate platform and protocol assumptions.

native count remains 8,280 actual attempts, including the R41 pilot's 96
attempts already counted in the preceding collection. Model executions,
mapping and timing attempts are counted separately in component summaries.
